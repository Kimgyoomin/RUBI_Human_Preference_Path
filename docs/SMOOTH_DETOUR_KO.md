# 부드러운 평지 우회 경로 — cosine-bypass-v2

## 변경 범위

기존 세 선분의 사다리꼴 우회 경로를 raised-cosine 곡선으로 교체한다. 출발점 (0,0), 목적점 (6,0), 플랫폼 크기 0.8 × 0.7 m, 원본/웹용 로봇 자산, ONNX, PD, 물리/정책 주기, 재생 배율, 응답 선택/시청 조건은 바꾸지 않는다.

## 경로와 거리

`y(x) = A / 2 × (1 - cos(2πx / 6))`, `0 ≤ x ≤ 6`.

연속 곡선의 양 끝 접선은 +X 방향이며 내부에 꺾이는 꼭짓점이 없다. 다만 이 곡선은 원 하나의 일부가 아니고 곡률이 변하는 곡선이다. 480구간으로 샘플링하므로 실제 추종 대상은 조밀한 polyline이다. 시작/종료 polyline heading은 0에 매우 가깝지만 연속 곡선 접선과 수치적으로 같지는 않다. 실제 로봇의 도착 yaw를 0으로 강제하지도 않는다.

A는 표시 및 추종에 쓰이는 polyline 길이가 `6 + detour`가 되도록 48회 이분법으로 구한다. 추가거리 0.8 m에서 A는 약 1.461579 m, 경로 길이는 6.8 m이다. 런타임 길이 오차 허용값은 1e-6 m이다. 진입/종료 시 직선 구간을 별도로 이어붙인 C2 경로라는 주장은 하지 않는다.

## 여유 공간

모든 선분과 플랫폼의 닫힌 XY 직사각형 사이 최소거리를 검사하고 중심선 거리 0.4 m 이상을 요구한다. 꼭짓점이나 중앙 x 한 지점만 검사하지 않는다. 추가거리 0.4 m의 최소 중심선 거리는 약 0.597685 m이다. 이 검사는 기존 planner의 보수적 중심선 여유 기준이며 발 디딤, 자세, 실제 추종 오차까지 포함한 전신 충돌 안전 인증은 아니다.

## 데이터와 버전

- `scenario.id`에 `cosine-bypass-v2`를 포함한다.
- `scenario.geometry`에 경로 버전/진폭/길이 오차/최소 중심선 거리와 직선·우회 경로의 길이, 시작·종료 heading, 최대 곡률, 절대 곡률 적분을 저장한다.
- 연속 곡선의 접선 및 곡률 정보와 sampled polyline 지표를 구분한다. 이들은 계획 경로 지표이지 실제 로봇의 yaw 측정값이 아니다.
- 기존 내보내기와 응답 JSON은 scenario 전체를 포함하므로 위 정보도 저장된다. 상세 기하 분석에는 JSON을 사용한다.
- 연구 ID를 `rubi-hpp-cosine-v2`로 분리하고 draft를 유지한다. 이전 사다리꼴 설문 진행상태를 이어받지 않는다. 과거 localStorage 응답은 삭제하지 않으며 분석 시 experimentId와 geometry.version으로 분리한다.
- 응답 API 연결 시 `RUBI_EXPERIMENT_ID=rubi-hpp-cosine-v2 RUBI_STUDY_STATUS=draft npm run api`로 일치시킨다. 기존 ID의 서버를 사용하면 웹의 연결 검사가 의도적으로 거절한다.
- rollout contract를 v2로 올렸다. 캐시 키는 형상 버전, 실제 경로 점, 물리 조건, 정책/모델 hash를 포함한다. 직접 경로는 우회거리만 달라질 때 계속 재사용한다.

## 성능과 제어

481개 제어점을 481개의 점 표식으로 만들지 않는다. 화면 표식은 호 길이를 기준으로 0.12 m마다 배치해 최대 약 71개를 사용한다. 경량 메시, normal 재사용, 픽셀 비율/그림자 설정을 유지한다. Follower의 lookahead 0.45 m, gain 2, yaw 제한 ±0.8 rad/s, 속도 감속 법칙과 도착 반경 0.14 m는 그대로 두고 선분 길이를 재사용한다.

## 검증과 한계

자동 기하 검사는 전체 우회거리 범위의 길이/여유 공간, 접선/대칭성, 표식 수, 버전, 기구학적 추종을 검사한다. 기구학 테스트는 learned RUBI 보행 검증이 아니다. 별도의 Chromium 검사에서 실제 ONNX + MuJoCo 평지 A/B 완주와 캐시 재사용, 5 cm 플랫폼을 피하는 최소·최대 우회거리의 완주를 검사한다. 통과 여부는 해당 CI 로그를 확인한다.

본 조사 전에 다양한 참가자 기기에서 미리보기와 실제 추종을 확인해야 한다. 거리 증가에 따라 진폭과 곡률도 변하므로 회전 부담이라는 교란변수가 완전히 제거된 것은 아니다. 곡률 지표를 남기는 것만으로 거리의 인과 효과가 분리되는 것도 아니다. 다른 높이/속도/지형 조합의 보행 안정성은 별도 검증 대상이다.
