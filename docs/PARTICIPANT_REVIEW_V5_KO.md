# 참가자 화면 v5: 다시 시작 · 짧게 보기 · 다시 보면서 답하기

## 이번 변경

- 완료 화면에 `처음부터 다시 해보기`. 확인 후 새 sessionId와 문항 순서를 만들며, participantId는 유지한다.
- 이전 세션은 브라우저에 별도 보관한다. 기존 Sheets 응답, 다른 사이트 저장값, 모델 캐시는 지우지 않는다. 미저장 응답이 있으면 재시작을 막는다.
- 새로운 protocolVersion `guided-self-paced-v5`와 labelConditionVersion `core-view-no-labels-review-with-choice-v2`. 이전 v4 저장값은 그대로 두고 새 흐름을 시작한다.
- 처음 보는 각 경로는 출발부터 플랫폼의 먼 쪽 끝 + 0.4 m 지점까지 확인한 뒤 `이 정도면 알겠어요`로 관찰을 끝낼 수 있다. 현재 플랫폼은 x=3 m 중심, 깊이 0.8 m이므로 공통 확인 지점은 x=3.8 m이다.
- 이 기준은 **파일럿 UX 설계값**이며 사람의 이해도를 입증한 통계적 문턱이 아니다. A/B에 같은 공간 기준을 적용한다. 아예 안 본 경로를 선택하거나 단차를 만나기 전에 건너뛰는 것은 허용하지 않는다.
- 화면이 끊기거나 정상 속도보다 느리게 표시된 첫 관찰은 재확인이 필요하다. 기존 real-time factor 0.90 / 최대 표시 간격 400 ms 기준은 유지한다.
- 짧게 보기를 눌러도 실제 물리 계산은 목표까지 마쳐 성공 여부를 검사한다. 보이지 않은 나머지 구간은 시청으로 계산하지 않는다. 이 구간의 계산 때문에 짧은 대기는 남을 수 있다.
- 두 경로 확인 후에는 3D 화면 옆(모바일은 아래)에 선택 버튼을 둔다. 다시보기 중 아무 때나 답할 수 있다. 선택 시 재생을 취소하고 정리가 끝난 뒤 저장하므로 다음 문항 상태와 경합하지 않는다.
- 처음 관찰할 때 높이/추가거리 수치는 계속 숨긴다. 두 길을 확인한 뒤에는 다시보기 중에도 3D 화면 **바깥**의 비교 카드에 수치가 남는다. 이전 numeric-on-choice-only 조건과 다르므로 같은 조건으로 합쳐 분석하지 않는다.
- 데스크톱 첫 화면의 캔버스 높이 260~420 px, 모바일 230~330 px. 비교 중에는 화면과 선택 카드를 함께 보여 준다. 로봇 카메라/물리/정책은 변경하지 않는다.
- participant copy에서 `선호`, `제어기`, `세션`, `플랫폼` 등을 일상 표현으로 교체한다. 내부 분석 필드는 유지한다.

## 기록

`previewCoverage`는 실제로 화면에 표시한 구간의 합집합으로 계산한다. `directCoverage`와 `detourCoverage`로 기존 Sheets 수집기가 기록한다. 짧게 보기 때문에 1보다 작은 값도 정상이며, 예전 v4의 전 구간 시청 기준을 v5에 그대로 적용하면 안 된다.

추가 전송/로컬 기록: `observationPolicy`, `previewEvents` (시청 구간/시간/중단/짧게 보기/표시 품질), `choiceDuringReplay`, `repeatIndex`, `previousSessionId`.

현재 배포된 Apps Script는 위 추가 필드를 모두 열로 매핑하지 않는다. 중앙 Sheets에는 기존의 coverage 열, labelConditionVersion, queryReason, participantId/sessionId 및 나머지 기존 열이 기록된다. 상세 이벤트는 브라우저의 전체 응답에 보존된다. 전체 이벤트의 영구 중앙 보존은 Apps Script 스키마를 확장하고 재배포할 때 보완해야 한다.

같은 기기에서 반복 참여한 사람을 새로운 사람으로 집계하지 않는다. participantId는 유지되며 sessionId만 달라진다. 다른 기기/시크릿 창까지 같은 사람이라고 판별하는 기능은 없다.

## 유지한 범위

- 5/7/9/11 cm, 16문항 고정 파일럿. adaptive search는 이번 변경에 없다.
- 0.50 raw navigation command, 실제 achieved speed 기록, resident MuJoCo/ONNX, Start 초기화 유지.
- Google Apps Script 주소/권한/Sheets 기존 데이터는 변경하지 않는다.
- 사전 경험은 처음에 받고, 기존 수집기의 완료 의미에 맞춰 종료 시 원격 profile을 확정한다. 중도 이탈자의 배경 정보 즉시 중앙 저장은 기존과 동일하게 미완이다.

## 검증

단위 검사: 공통 관찰 지점, 화면 품질 게이트, 실제 coverage, 미저장 응답 보호, 보관 실패, ID 보존, 한국어 문구 검사.

브라우저 검사: 실제 RUBI/ONNX 두 높이의 A/B 실행, 짧게 보기, 다시보기 중 응답, 중복 클릭, 다음 문항으로의 경합 방지, 작은 화면 배치, 완료 후 새로고침/재시작 및 이전 답변 보존. 응답 저장은 테스트용으로 가로채며 실제 연구 시트에는 쓰지 않는다.
